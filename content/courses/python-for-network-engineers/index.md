You know your network. You've seen the demos. Now you want to write the script yourself. This course takes you from zero Python to a working script that connects to network devices and reads information from them.

## What you'll learn

- Python basics in a network context: variables, lists, dictionaries, loops and functions
- Reading and writing files, and working with structured data (JSON)
- Connecting to network devices with Netmiko and running show commands
- Turning CLI output into data you can actually use
- Handling errors, so your script doesn't fall over on the first unreachable device
- Working with the everyday toolset of an automation engineer: VS Code, Docker, dev containers and Containerlab, set up on your own laptop so you keep using them after the course
- Stretch goal: your first API call to a device

## How it works

- Hands-on: at least half of the day you are writing code
- Lab: two virtual Nokia SR Linux devices in Containerlab, running on your own laptop
- Every block builds toward one goal: a script you can take home and use on your own network

## Who it's for

Network engineers with little or no programming experience. No prior Python knowledge needed.

## Practical

- Bring a laptop with admin rights, so you can install VS Code and Docker. You get setup instructions a week before the course.
- No network equipment needed: the lab runs on your laptop, and you keep it afterwards.
- The course is taught in Dutch or English, depending on the group. The material is in English.
- You book and pay through the sign-up link of each date, and get an invoice with VAT, ready for your employer.

## After this course

You go home with a script that logs in to devices, runs show commands and gives you the output as data. More importantly, you can read it, change it and run it yourself.

A good first step on Monday: point it at a few devices in your own lab or network, and collect one thing you now check by hand, such as software versions or interface status.
