[NLNAM](https://net-auto.nl/) is a volunteer-run, community-driven meetup for network engineers, DevOps practitioners, and software developers modernizing infrastructure through code — covering topics like Infrastructure as Code, Source of Truth, config management, network programming, monitoring & observability, cloud networking, and validation & testing.

In 7 minutes, I'll cover:

- What NLNAM is and who it's for
- What a typical meetup looks like
- How to get involved — as an attendee, speaker, or host

If you've ever wanted to talk about the automation side of your network — the scripts, pipelines, and tooling behind the CLI — this is an open invitation.
